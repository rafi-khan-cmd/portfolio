About

Turning data into decisions.

I work across the full data lifecycle — analysis, data science, engineering, and machine learning — turning raw, messy data into pipelines, dashboards, and models that drive measurable outcomes.

On the data side, I handle acquisition, cleansing, and ETL through to analysis, visualization, and reporting. On the modeling side, I build machine-learning systems spanning NLP, computer vision, and time-series forecasting. Alongside the work, I've taught 650+ students and led technical ML workshops, so I can both build a system and explain the reasoning behind it clearly.

My projects range from ETL pipelines and interactive dashboards to forecasting models and AI-powered applications using Hugging Face models. The work is grounded in Python, R, SQL, and the modern data stack — from data lakes and warehouses to scikit-learn, PySpark, Power BI, and Tableau. I still ship full-stack apps when a model or dashboard needs a home, but the focus is always on turning data into decisions.
